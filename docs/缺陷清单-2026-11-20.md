### 明细

**W-01 锁冲突丢目标**
`withWarningStudentLock` 重试 3 次后返回 `{locked:false}`，批量层记为 `skipped_locked` 只累加计数。队列消费路径会因此抛错重试（正确），但 `attendance.controller.ts:3005`（日记录录入）、`:1601`（`dispatchWarningRecalcAsync`）只 `.catch` 打日志，目标直接消失。
修复方向：锁冲突写入待重算队列（Redis ZSET 或 outbox 表），由调度任务重放；不要当"算过了"。

**W-02 去重键无版本**
`enqueueItems` 先 `SET NX` 占位（TTL 900s）再 `XADD`。同一 (学生,日期,课程,课次) 的第二次更新会被去重；若第一条消息在另一次写库提交前被消费，读到旧快照后该记录永不重算。进程在 SETNX 与 XADD 之间崩溃也会让该目标 15 分钟内全部被去重。
修复方向：去重键带事件版本/`updated_at`；或用 outbox 表保证"业务写入 + 入队"同事务。

**W-03 重复认领**
`XAUTOCLAIM ... <consumerName>` 把空闲超 30s 的消息认领给**自己**。批量处理超过 30s 时同一条消息被并发再处理 → 抢锁失败 → 整批重试 → 5 次进 DLQ。
修复方向：可见性超时按批量耗时上调（或加心跳），认领逻辑与并发度对齐。

**W-04 MAXLEN 裁剪**
`XADD ... MAXLEN ~ 10000` 不看 pending 状态，积压超限直接裁掉未消费消息，DLQ 也收不到。
修复方向：按峰值调大或去掉 MAXLEN（成功后已 XDEL，不会无限增长）。

**W-05 无水位竞态**
重算是 ReadCommitted，且每个 metric/window 一个独立事务。扫描 `attendance_records` 与写预警之间没有快照一致性；考勤写入（签到/改状态/补缺勤）不持有学生锁。全仓库无 `GET_LOCK` / `FOR UPDATE` / `Serializable`（已 grep 确认）。
修复方向：outbox + 学生级 `last_recalc_at` 水位；或把"读-算-写"放进单个 `Serializable` 事务并加重试。

**W-06 兜底吞异常**
`scheduleAffectedRecords` 入队失败后回退调 `generateWarningsForAffectedRecords`（默认 `failOnError:false`），单学生异常只打日志，返回 0 条，调用方当成功。

**W-08 阈值被绕过**
```ts
let matchedRule = rules.find(r => count >= r.threshold) || null;
if (!matchedRule && rules.length > 0) matchedRule = rules[rules.length - 1]; // 最低阈值
```
规则按阈值降序，最后一条是最低阈值 → 1 次缺勤 vs 阈值 3 也会建预警；下方 `if (!matchedRule) closeWarnings` 成死代码。且 `eventCountByCourse` 只统计当前课程，跨课程日累计阈值永远达不到。

### 明细

**A-05 课次列表泄露二维码**
返回体含 `scan_token`（当前二维码 token），持 `attendance:read` 的班主任可拿到全校正在进行的课次并代替他人签到。
修复方向：加 `@DataScope({entity:'session', field:'id'})`，`where` 按 `dataScope.classIds` 过滤；`scan_token` 只对课次所属教师返回。

**A-07 默认放行（根因级）**
`PermissionGuard` 在方法没有 `@Permissions` 时 `return true`，且没有注册 `APP_GUARD`，鉴权完全依赖每个 controller 手写装饰器。今天修的 A-01/A-03 都属于"漏写装饰器"这一类。
修复方向：`PermissionGuard` 改为默认拒绝；注册全局 `AuthGuard`（`@Public` 显式放行）。**这一条会一次性改变全部 37 个 controller 的行为，必须单独排期 + 全量回归。**

**A-08 / A-09 写入侧无范围**
同类问题：读接口补了 `@DataScope`、写接口漏了。可用现有的 `assertCanManageClass(classId)` 复用。

**D-07 校验全局缺位**
